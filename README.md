# AI-Powered Student Analysis Dashboard Using Image and Video Processing

This repository contains the complete, dual-platform implementation:
1. **Python / Flask Full-Stack AI & Computer Vision System** in [`/student-analysis-dashboard`](./student-analysis-dashboard)
   - Real OpenCV image and video facial detection & tracking
   - Scikit-learn Random Forest predictive academic risk engine
   - PyMuPDF & pdfplumber document ingestion pipeline
   - ReportLab executive PDF report generator
   - SQLite 3 ACID database with 35 realistic synthetic students
   - Full HTML5/CSS3/JavaScript dark AI dashboard with Chart.js visualizations
   - 9 Automated unit & integration tests passing
2. **Native Android Jetpack Compose Application** in [`/app`](./app)
   - State-of-the-art dark AI user interface with biometric camera scanning, live interactive charts, full student CRUD, risk prediction, and offline database persistence!

For complete Python setup, Windows instructions, and architecture details, see:
[`student-analysis-dashboard/README.md`](./student-analysis-dashboard/README.md)
